# Code of Conduct

## Our Pledge

We want code2pia to be a practical, respectful, and useful project for privacy engineers, developers, security teams, legal teams, and public-interest contributors.

We pledge to make participation in this project a harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socioeconomic status, nationality, personal appearance, race, caste, color, religion, or sexual identity and orientation.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent, especially across disciplines.
- Keep discussions focused on improving the tool.
- Use synthetic or redacted examples when discussing privacy findings.
- Welcome newcomers and explain project conventions clearly.

## Unacceptable Behavior

- Harassment, discrimination, or personal attacks.
- Publishing private information without explicit permission.
- Sharing real personal data, credentials, secrets, or confidential customer information in public project spaces.
- Repeatedly derailing technical or governance discussions.

## Enforcement

Maintainers may remove comments, close issues, reject pull requests, or restrict participation when behavior conflicts with this code of conduct.

If you need to report a conduct issue, contact the maintainers privately.

## Attribution

This code of conduct is inspired by the Contributor Covenant and adapted for this project.
